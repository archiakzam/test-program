Выполнено Агзамовым Артуром.

Программа под Linux на C++, которая собирает системные метрики (CPU, RAM, температура, диски, процессы) и отображает их через веб-интерфейс с живыми графиками и таблицей процессов.

Возможности:
  - Сбор метрик:
    - Загрузка CPU (из `/proc/stat`)
    - Использование RAM (из `/proc/meminfo`)
    - Температура CPU (из `/sys/class/thermal`)
    - Занятость дисков (statvfs по точкам монтирования, фильтрация виртуальных ФС)
    - Список процессов: PID, имя, %CPU, память в MB (из `/proc/[pid]/stat` и `/status`)
  - Веб-интерфейс:
    - Графики CPU и RAM
    - Показатели температуры
    - Список дисков с процентом заполнения
    - Таблица процессов с сортировкой по клику на заголовок
  - Асинхронная многопоточная архитектура:
    - Каждый сборщик работает в своём потоке с заданным интервалом
    - HTTP-сервер  отдаёт JSON по запросам

Требования:
  - Компилятор g++ с поддержкой C++17
  - Утилита make
  - ОС Linux (используются /proc, /sys/class/thermal, statvfs)

Инструкция к сборке:
  1. СКачай проект, оставь расположение файлов в исходном виде
  2. Скачай make
    - Пример: sudo apt install make
  3. Открой терминал в папке проекта и выполни make
  Если нужно изменить порт HTTP, то отредактируй main.cpp (Порт по умолчанию 1234).

Для запуска программы после сборки выполни ./monitor в папке проекта, а затем открой в браузере ссылку http://localhost:1234.

Чтобы остановить выполнение программы, в терминале(В котором запускалась программа) нажми CTRL+C

Доступные HTTP эндпоинты:
  - GET /stats – возвращает JSON
  Пример:
    json
    {
      "timestamp": 1480000000,
      "cpu": 12.5,
      "ram": 34.2,
      "cpu_temp": 45.3,
      "disks": [
        {"mount": "/", "usage": 68.5},
        {"mount": "/home", "usage": 42.0}
      ]
    }
  - GET /processes – массив процессов
  Пример:
    json
    [
      {"pid": 1234, "name": "firefox", "cpu": 8.2, "mem_mb": 1024},
      ...
    ]
  - GET / – веб-интерфейс

Примечание:
  - В проекте используется стороняя библиотека nlohmann/json для облегчения работы с json. проект автора находится по ссылке https://github.com/nlohmann/json
  - Генерация документации по коду:
    - В проекте есть комментарии в стиле Doxygen. Чтобы сгенерировать HTML-документацию выполни в терминале: "doxygen Doxyfile" (Предварительно выполнив sudo apt install doxygen)
    - Документация доступна в "Проект"/docs/html/index.html
