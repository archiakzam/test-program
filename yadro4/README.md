Программа под linux на c++, которая предназначена для сканирования каталога на наличие медиафайлов (изображения, видео, картинки) и последующего вывода списка медиафайлов в формате JSON.

Возможности:
  - Сканирование каталога с заданым интервалом
  - Два режима работы:
    1. Запись в файл (Сохраняется в ~/media_files).
    2. Доступ к JSON (Доступен по адресу http://localhost:1234/media_files)

    Стандартно доступ по HTTP, при желании можно записывать в файл.

Расширение файлов:
  - Аудио: `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`
  - Видео: `.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`
  - Изображения: `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.tiff`

Требования:
  - Компилятор g++ с поддержкой версии c++17
  - Утилита make
  - ОС - Linux

Инструкция к сборке:
  1. Скопируйте проект в одну папку
  2. Откройте терминал в этой папке
  3. Выполните make

При сборке:
  - Если вы хотите использовать запись в файл необходимо указать данный флаг сборки: ENABLE_HTTP=0.

  Пример:
  make ENABLE_HTTP=0

Параметры запуска:
  Программа media_scanner принимает следующие параметры командной строки

  - Обязательные:
    --dir <путь>            Каталог, который необходимо сканировать
    Пример: ./media_scanner --dir /home/user/Music

  - Опциональные:
    --interval <секунды>    Интервал между сканированиями(Положительное число)
    По умолчанию 60 секунд.

    --http                  Включить режим HTTP-сервера (иначе – запись в файл ~/.media_files).
    По умолчанию выключен. Если при сборке указано ENABLE_HTTP=0, то данный параметр недоступен.

    --port <порт>           Номер порта для HTTP-сервера (только вместе с --http).
    По умолчанию 1234.

    --help                  Показать справку.

Подробности о режимах:
  1. Режим записи в файл.
    Программа работает в бесконечном цикле: каждые --interval секунд сканирует каталог, обновляет JSON в памяти и записывает его в файл ~/.media_files. Остановка – Ctrl+C.
  2. Режим HTTP (--http)
    Запускается фоновый поток, который каждые --interval секунд сканирует каталог и обновляет JSON. 
    Основной поток запускает HTTP-сервер, который обрабатывает запросы GET /media_files и возвращает актуальный JSON.
    Сервер работает до нажатия Ctrl+C (завершает оба потока).
    
Пример использования:
  Сканирование каждые 5 секунд, результат в файл
  ./media_scanner --dir ~/test_media --interval 5

  HTTP-сервер на порту 8080, сканирование раз в 10 секунд
  ./media_scanner --dir ~/Videos --interval 10 --http --port 8080

  Показать справку
  ./media_scanner --help
